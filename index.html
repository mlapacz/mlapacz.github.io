Now

Since December 2023 I have been building the AWS platform on which Ericsson's generative-AI and LLM projects run. Everything is defined in CloudFormation, so an environment is a reviewable file rather than a sequence of clicks. Day to day that means Python, Docker, CI/CD pipelines, and the security boundaries that let research teams move quickly without leaking anything.

Alongside that I am building a RAG application on a knowledge fabric. An ontology describes the entities and relations of the domain, so retrieval follows the structure of the knowledge instead of relying on vector similarity alone.

Most of my code now starts as a conversation with an agent. I work with Claude Code and Pi every day, keep my agent setup and self-written extensions under version control, and wrote a relay that puts several Pi sessions in the browser. The agents draft; I decide what ships.

Off the clock I write JavaScript for the fun of it, an enthusiasm that dates back to ES6, and keep an eye on Rust.

How I work

  • T-shaped, with a fat stem. Deep in telecom and cloud infrastructure; wide enough across languages, from PLEX-C to Go, to choose the right one rather than the familiar one.
  • Mature beats novel, until it doesn't. Twenty years of telecom taught me to judge a technology by how it fails under load, not by how it demos. Most frameworks do not survive that question.
  • Functional by default. Immutable data and small pure functions are how a codebase stays understandable in year twenty. I have maintained enough year-twenty code to mean it.
  • The pipeline is part of the product. From PowerPC boards to Kubernetes I have owned the build and the deployment as much as the code. A feature that cannot be shipped repeatably is not finished.

  • 2026open source

    Tooling for coding agents

    agent-comm is a relay that fronts several Pi coding-agent sessions: a real terminal in the browser through xterm.js, plus an A2A HTTP surface so other agents can talk to them. Sessions dial out over WebSocket, so nothing needs an inbound port. agent-setup keeps my agent configuration and self-written extensions, such as automatic AWS SSO re-login, reproducible on any machine.

    TypeScript · Node · WebSocket · xterm.js · A2A
